# obsidian-from-rednote

> 把小红书收藏的笔记同步到本地 Obsidian 仓库（Vault）。灵感来自 [rednote.2obsidian.com](https://rednote.2obsidian.com/)。

Sync your RedNote（小红书）favorites/collections into a local Obsidian vault as Markdown.

## 项目目标

- 同步小红书收藏夹中的笔记：标题、正文、图片、作者、标签、原文链接
- 转换为带 frontmatter 的 Markdown，附件（图片等）归档到 vault
- 支持增量同步，不重复下载已有内容
